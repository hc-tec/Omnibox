  核心设计原则

  1. 数据产物是一等公民

  interface DataArtifact {
    id: string;
    name: string;
    type: 'dataset' | 'analysis' | 'insight' | 'document';

    // 来源追溯
    source: {
      workflow_id: string;
      step_id: string;
      created_at: timestamp;
    };

    // 数据本体
    data: any;
    schema: JSONSchema;  // 结构定义，支持类型推断

    // 可视化建议
    suggested_views: ViewSpec[];

    // 引用关系
    derived_from: ArtifactRef[];  // 我是从哪些产物派生的
    used_by: ArtifactRef[];       // 谁在用我
  }

  效果：任何产物都可以被引用、可视化、导出、分享。

  2. 工作流是可执行的 DAG

  interface Workflow {
    id: string;
    name: string;

    // 步骤定义（DAG）
    steps: {
      [stepId: string]: {
        type: 'fetch' | 'process' | 'analyze' | 'output';
        tool: string;          // 使用什么工具
        params: any;           // 参数（可引用变量）
        depends_on: string[];  // 依赖哪些步骤
        output: string;        // 输出产物的名称
      }
    };

    // 变量定义（模板化的关键）
    variables: {
      [name: string]: {
        type: 'string' | 'number' | 'datasource';
        default?: any;
        description: string;
      }
    };
  }

  效果：工作流可以被保存、分享、模板化。

  总结

  | 维度   | 当前（研究卡片） | 目标（工作流工作台） |
  |------|----------|------------|
  | 数据位置 | 锁在卡片详情页  | 统一数据层，随处可用 |
  | 任务形态 | 单次查询     | 多步骤工作流     |
  | 中间结果 | 不可见      | 每步都有产物，可回溯 |
  | 跨源分析 | 手动打开多个卡片 | 自动流转，一键关联  |
  | 复用性  | 无        | 模板化，一键分享   |
  | 监控   | 无        | 仪表盘持续追踪    |

  核心理念：
  数据是流动的资产，工作流是可复用的知识，决策才是最终目的。
